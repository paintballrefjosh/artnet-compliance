Fixture Groups

Fixture groups let one rule cover several fixtures at once (e.g. "House Whites", "Stage Front"). A group can be created empty — assign fixtures whenever you're ready.

Rules

The shared pool of compliance thresholds. Rules marked "always active" are enforced constantly; the rest are enforced only while a cue that assigns them is active.

Display only — applies everywhere in the app. Values are always stored and checked as raw DMX.

Cues

A cue is a named set of rule assignments. Only one is active at a time — its rules are checked in addition to every rule marked "always active".

Compliance Report

A frozen snapshot checking every cue against current live values, as if each were active on its own — not just whichever cue happens to be selected right now.
